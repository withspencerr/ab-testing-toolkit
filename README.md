# A/B Testing Toolkit

**Goal:** Evaluate marketing or product experiments using Python & Google Colab.  
**Tools:** Python · statsmodels · scipy · matplotlib  

## 🎯 Highlights
- ✅ Conversion rate (proportion) z-test  
- ✅ Revenue (mean) t-test  
- ✅ Power & sample size estimation  
- ✅ Ready-to-present visuals for executive insights  

## 🚀 How to Reproduce
1. Open `ab_testing_toolkit.ipynb` in **Google Colab**  
2. Click “Run all”  
3. See charts and statistical results automatically generated  

## 📊 Example Output
- Conversion lift: +1.5%  
- p-value < 0.05 → Statistically significant  
- Required sample per group ≈ 2,500 (for 80% power)
